Privacy policy

Last updated: 17 October 2026

This policy describes the intended privacy practices for the YelloTrace website. It must be checked against the live hosting configuration before launch.

1. Who operates this site

YelloTrace is an independent project associated with CNRCO. The website is published through GitHub Pages in the project repository. GitHub provides the hosting service and may process technical information as described in its own policies.

2. Information collected by the site

The current website has no account registration, contact form, advertising scripts, or analytics code in its page source. Visiting a website can still result in technical request data being processed by the hosting provider, such as IP address, browser information, request time, and requested resource. The exact data, retention period, and access arrangements depend on the hosting provider and its current practices.

3. Cookies and third-party services

The current page source does not intentionally set cookies or load analytics services. The hosting platform, browser, or any service added later may operate differently. This statement must be reviewed whenever the site configuration or external resources change.

4. How information is used

Technical information processed by the hosting provider may be used to deliver, maintain, secure, and troubleshoot the website. YelloTrace does not currently provide a form or account system through which visitors submit personal information.

5. Retention and security

YelloTrace does not control the hosting provider's internal log retention. The provider's documentation and policies govern its processing. Reasonable care should be taken to keep the website and repository access secure.

6. Your choices and requests

If you have a privacy question or request, contact the project maintainer through the CNRCO GitHub profile. Do not include sensitive personal information in a public issue. The appropriate response may depend on applicable law and which party controls the relevant data.

7. Changes to this policy

This policy may be updated if the site's hosting, features, or legal obligations change. The date above should be updated when substantive changes are made.
